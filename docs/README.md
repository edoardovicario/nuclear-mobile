# Nuclear Mobile PWA
Versione indipendente di Nuclear (AGPL-3.0-only, licenza nella radice del repository). Pubblicare Settings > Pages > Deploy from a branch > pwa > /docs > Save. Aprire https://edoardovicario.github.io/nuclear-mobile/ dopo la pubblicazione. Safari > Condividi > Aggiungi alla schermata Home; Android Chrome > menu > Installa app. Nessun Xcode o server. Il service worker conserva l'interfaccia, non la musica. Internet Archive riceve ricerca e richieste multimediali; le licenze sono dichiarate dagli uploader e non garantite. Preferiti e playlist locali. Riproduzione in background dipendente dal sistema; plugin desktop non integrati. Test facoltativo: node docs/archive.test.mjs. Verificare su dispositivi reali.
